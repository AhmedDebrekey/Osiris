# Animation test fixture

Original procedural test geometry and motions generated by `tools/generate_animation_fixture.cjs`.
No third-party model or animation content. Six joints, four-weight vertex format, and Idle,
Walk, and Run clips. These are deliberately simple limb swings for testing, not production motion.

`test_character.gltf` uses an external buffer and PNG. `test_character.glb` contains the same
geometry, rig, clips, and embedded PNG. Keep the glTF's companion files together.
