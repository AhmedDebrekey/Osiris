# Book cloth textures

Generated with the built-in image generation tool using the imagegen skill.
Applied to the three existing shelf books in `scenes/apartment.json`.
No external source images were used.

Files: `cloth_blue.png`, `cloth_green.png`, `cloth_red.png`.

## Prompts

Three separate generations used the following prompt, substituting COLOR with
"muted navy blue", "muted sage green", and "muted oxblood red", respectively:

Use case: photorealistic-natural. Asset type: tileable albedo game texture for a hardcover book cloth binding. Generate a square full-bleed flat swatch of COLOR tightly woven bookbinding cloth, fine subtle fabric grain, slight age and handling variation, evenly colored, restrained contrast. Orthographic surface only, neutral diffuse illumination, no shadows or baked highlights. Seamless edges. No lettering, no borders, no book object, no mockup, no logos, no watermark. The entire image is the material surface, ready to map onto a small book cover and spine.
